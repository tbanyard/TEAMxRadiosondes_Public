The data in these files is parsed from a combination of sources, including BUFR files from Bozen (KIT, DE) and Kolsass (UIBK, AT) and netCDF files from Sterzing (NCAS, UK). At present, this data should be considered preliminary and may contain inconsistencies as it has not undergone thorough testing and quality-control checks. Please contact tpb38@bath.ac.uk for more info and appropriately credit the relevant organisation for onward use.

The file name format is 'YYYYmmDDHHMMSS_SSSSSSSS_LLLLLLLL_IIII_vX.X.ABC':
YYYYmmDDHHMMSS - Launch Date and Time
SSSSSSSS - Radiosonde Serial Number
LLLLLLLL - Site Launched From
IIII - Institution of Origin
vX.X.ABC - Version of Data and Initials (ABC) of File Creator

Data Versions:
v1.0 - Initial data parsed directly from BUFR and TXT files.
v1.1 - Data processed from netCDFs created by NPH (UoB).
v2.0 - Data processed from netCDFs created by PR (NCAS).
